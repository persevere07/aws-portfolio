## 📌 Project Overview

This is a fully static portfolio website built using **HTML and CSS**, deployed on AWS using the Free Tier.  
It showcases my skills in **Cloud Computing, DevOps basics, and Linux environments**.

The project also integrates **Git & GitHub** for version control and continuous updates.
